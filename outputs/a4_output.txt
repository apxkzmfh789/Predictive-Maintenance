A4-3. 시뮬레이터 검증 — 오작동과 진짜 이상의 구분 가능 여부
====================================================================
튀는 값의 두 종류
  (A) 센서 오작동 = 주입한 스파이크 : 219건 (토크 기준)
  (B) 진짜 설비 이상 = 고장 라벨    : 1294건

[토크 IQR 이상치 판정 vs 실제 정체]
실제정체    센서오작동     정상  진짜고장
IQR이상치                    
False      91  53520  1281
True      128    445     6

AI4I와 시뮬레이터에서 IQR 결과가 반대
  - AI4I      : 토크 IQR 이상치 중 진짜 고장 89.9%
  - 시뮬레이터: IQR 이상치 579건 중 센서오작동 128건(22.1%),
                진짜 고장 6건(1.0%)
                고장 1281건은 IQR 경계 안쪽에 위치 (전체 고장의 99.5%)

원인: 8~40배로 튀는 센서 오작동이 사분위수를 밀어올려 IQR 경계가 바깥으로 이동
  → 정상보다 약간 높은 진짜 고장의 토크가 경계 안쪽에 남음

IQR 결과는 분포의 꼬리에 무엇이 있느냐에 따라 달라짐
  같은 규칙이 데이터에 따라 고장을 지우기도, 놓치기도 함
  → 이상치 규칙 적용 전 무엇이 걸리는지 확인 필요

A4-4. 구분 단서 — 지속시간과 센서 간 정합성
====================================================================
    판정 규칙  걸린 행  센서오작동 포함  진짜고장 포함  오작동 비중%
Hampel 단독   865       209       47     24.2
 지속 3분 이상     3         0        0      0.0
전류와 동시 이상   103         2       16      1.9

규칙별 결과

 · Hampel 단독      : 865행 중 센서오작동 비중 24.2%
                     급변만 보면 오작동이 함께 포함됨

 · 지속 3분 이상     : 3행
                     시뮬레이터 고장(야간 저부하 PWF 등)은 급변이 아니라 서서히 진입해 Hampel에 잘 걸리지 않음
                     → 지속시간 규칙은 급변 후 지속되는 고장에만 유효

 · 전류와 동시 이상  : 103행 중 센서오작동 2건 (비중 1.9%)
                     Hampel 단독 24.2% 대비 감소
                     토크만 튀고 전류가 정상이면 물리적으로 불가능 → 센서 문제
                     두 센서가 함께 변하면 실제 부하 변화

단일 센서 이상치 규칙으로는 오작동과 고장 구분 불가
  → 여러 센서의 물리적 정합성으로 판단
